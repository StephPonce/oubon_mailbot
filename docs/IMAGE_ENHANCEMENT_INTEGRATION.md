## Architecture

### Complete Pipeline Flow

```
1. Product Discovery
   ↓
2. Get Original Images (AliExpress/Amazon/Shopify)
   ↓
3. AI Enhancement Pipeline:
   ├─ Download original image
   ├─ Remove background (FREE - rembg local AI)
   ├─ Generate lifestyle background (DALL-E 3 - $0.04)
   ├─ Composite product onto background
   ├─ Add branding/watermark
   └─ Save to local storage
   ↓
4. Deploy to Shopify with Enhanced Images
```

### Services Involved

1. **ProductImageProcessor** (`ospra_os/services/image_processor.py`)
   - Background removal (rembg)
   - Lifestyle background generation (DALL-E 3)
   - Product compositing (Pillow)
   - Branding/watermarking

2. **ImageStorage** (`ospra_os/services/image_storage.py`)
   - Local file storage (`/data/images/products/{product_id}/`)
   - HTTP URL generation
   - Cloud upload ready (Cloudinary/S3)

3. **ProductDeploymentService** (`ospra_os/integrations/shopify/deployment.py`)
   - Orchestrates entire deployment
   - Calls image enhancement pipeline
   - Integrates with Shopify API

## Usage

### Enable Image Enhancement (Default)

```python
from ospra_os.integrations.shopify.deployment import ProductDeploymentService

# Image enhancement enabled by default
service = ProductDeploymentService()

# Deploy product with AI-enhanced images
result = await service.deploy_product(product_data)
```

### Disable Image Enhancement (Backward Compatible)

```python
# Disable for faster deployments or cost savings
service = ProductDeploymentService(enable_image_enhancement=False)

# Will use original images
result = await service.deploy_product(product_data)
```

### Deploy with Custom Settings

```python
# Full control
service = ProductDeploymentService(
    shopify_client=my_client,
    enable_image_enhancement=True
)

# Deploy with AI description + AI images
result = await service.deploy_product(
    product_data=product,
    generate_description=True  # Claude Sonnet 4.5 description
)
```

## Error Handling

The integration includes comprehensive error handling:

1. **Graceful Degradation:** If image enhancement fails, uses original images
2. **Service Unavailable:** If OpenAI API key missing, disables enhancement automatically
3. **Individual Image Failures:** Continues with remaining images if one fails
4. **Cost Tracking:** Reports cost estimate even on failures
